One-time setup — in CRM go to Setup > Developer Space > Connections > Create Connection, pick the Zoho OAuth service, then:
  1. Create a connection with link name analytics and scope ZohoAnalytics.metadata.read (broader ZohoAnalytics.fullaccess.all also works), then authorize it.
  2. Create a second connection with link name crm and scope ZohoCRM.settings.ALL (or the minimal ZohoCRM.settings.functions.READ if your scope picker offers it), then authorize it.
  3. Reload this tab. Different link names are fine, just enter them above. Click any scope here to copy it.
