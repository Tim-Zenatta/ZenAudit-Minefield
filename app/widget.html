Run
One-time setup — in CRM go to Setup > Developer Space > Connections > Create Connection, pick the Zoho OAuth service, then:
  1. Create a connection with link name analytics and scope ZohoAnalytics.metadata.read (broader ZohoAnalytics.fullaccess.all also works), then authorize it.
  2. Create a second connection with link name crm and scope ZohoCRM.settings.ALL (or the minimal ZohoCRM.settings.functions.READ plus ZohoCRM.settings.reports.READ plus ZohoCRM.settings.automation_actions.READ plus ZohoCRM.settings.workflow_rules.READ plus ZohoCRM.settings.scoring_rules.READ plus ZohoCRM.settings.blueprint.READ plus ZohoCRM.settings.connected_workflows.READ if your scope picker offers them separately), then authorize it.
  3. For the optional Zoho Books check, create a third connection with link name books and scope ZohoBooks.settings.READ (broader ZohoBooks.fullaccess.all also works), then authorize it.
  4. For the optional Zoho Creator check, create a fourth connection with link name creator and scopes ZohoCreator.meta.application.READ plus ZohoCreator.meta.form.READ, then authorize it. Creator's Deluge scripts aren't readable via this API, only field names, so this check is informational only, same as Books.
  5. Reload this tab. Different link names are fine, just enter them above. Click any scope here to copy it.
